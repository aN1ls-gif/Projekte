Scrape: Scrapes the raw data from the yahho Finance stock market Website. Save as individual .json files.
ETL: A PySpark ETL Pipeline to process the raw data and saves in a Delta table
DataSimulation: Not part of the App, only for testing purposes. Resets all the Folders and files to their original Position and state to re-do the Pipeline with the same data.
Dashboard: A simple Streamlit Dashboard to view the data saved in the Delta table.
